The 5-Minute Beginner Route

The title describes a focused first-session route, not a guaranteed completion time. Your live game state can differ.

  1. 1

    Build some Fat

    Verified fact: The official description says clicking gains Fat.

    Guide strategy: Start with a short clicking session, then look at what changed in the live interface.

  2. 2

    Test your smash

    Verified fact: The official description connects bigger Fat with stronger smashes.

    Guide strategy: Try the next available wall instead of waiting for an unverified target number.

  3. 3

    Open the route

    Verified fact: Breaking walls is how the official description says new worlds unlock.

    Guide strategy: Move forward one wall at a time and learn the current requirement in-game.

  4. 4

    Collect Wins

    Verified fact: Wins and leaderboards are both named in the official description.

    Guide strategy: Treat your first Wins as proof that you completed the basic loop; optimize later.

  5. 5

    Review boosts

    Verified fact: Pets give boosts, while rebirth is described as making you stronger.

    Guide strategy: Read the current pet and rebirth screens before committing. Costs, effects, and resets are not confirmed here.

Understand the core loop

Verified fact

Click to gain Fat → bigger Fat creates stronger smashes → break walls to unlock worlds → collect Wins and climb the leaderboards.

Guide strategy

Learn one part of the loop at a time. Confirm that clicking changes Fat, test the next wall, and only then start comparing longer-term boost options.

The developer also names pets and rebirth as ways to become stronger. They sit around the core loop, but our public sources do not explain their current numbers or tradeoffs.

Before pets or rebirth

  • Read the current effect shown in the live game.
  • Check what the action costs before confirming it.
  • Look for any reset warning or retained-progress note.
  • Avoid advice that quotes a number without a current source.
Check in-game

Exact pet boosts, hatch details, rebirth costs, rebirth resets, and wall requirements are not confirmed by the sources used for this guide.
