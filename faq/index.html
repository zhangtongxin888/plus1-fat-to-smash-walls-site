Frequently asked questions

Fast answers, with confidence labels built in.

If a detail is not supported by the official description or Roblox public data, the answer says so plainly.

How do I gain Fat?

The official game description says: Click to gain Fat. The exact interface label and gain rate are not confirmed here.

What does Fat do?

The official description says bigger Fat means stronger smashes.

How do I unlock new worlds?

Break walls. Exact wall requirements and world details can change and are not confirmed by our sources.

What are Wins for?

The official description says to collect Wins and climb the leaderboards. It does not confirm how Wins may be spent.

Are there pets?

Yes. The official description says pets can be hatched for powerful boosts. Pet odds, costs, rarities, and boost values are not confirmed.

What does rebirth reset?

Not confirmed. Rebirth is described as making you stronger, but its cost, multiplier, and reset rules must be checked in-game.

Are there working codes?

No redemption codes were verifiable in the official sources checked for this guide. We will not list copied or rumored codes as fact.

Who developed the game?

The Roblox public game data lists WreckIt Games as the developer.

How many players can join a server?

The Roblox public game data lists a maximum server size of 8 players.

Is +1 Fat to Break Walls the same game?

No. It is a different Roblox title. This guide does not use its mechanics, values, or media.
